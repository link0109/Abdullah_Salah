# ELMOKADEM — New Project

مشروع جديد مستقل لموقع **المقدم فوتوغرافر | ELMOKADEM Photography**.

### تم تطويره
- تصميم Premium أسود/ذهبي ومتجاوب للموبايل.
- قسم أعمال Gallery.
- قسم خدمات.
- قسم Feedback من الـ5 Screenshots التي أرسلتها.
- سلايدر آراء العملاء + زر لعرض Screenshot الرسالة الأصلية.
- حجز المناسبة + الحقول الشرطية.
- إرسال بيانات الحجز إلى Google Apps Script الموجود في مشروعك.
- فتح WhatsApp برسالة الحجز جاهزة.
- روابط WhatsApp / Instagram / Facebook / TikTok / اتصال.
- دعم `?package=` مثل المشروع القديم.

### الصور
ضع صورك الأصلية في:
- `assets/background.jpg` للخلفية الرئيسية.

### مهم جداً
لم أضع Telegram Bot Token داخل المشروع الجديد. التوكن الذي كان موجوداً في الكود القديم كان مكشوفاً داخل JavaScript، لذلك لا ترفعه إلى GitHub. غيّر/ألغِ التوكن القديم من BotFather، وإذا أردت نظام تسجيل زوار نعمله لاحقاً من خلال Vercel Serverless Function + Environment Variables.

### النشر
ارفع المجلد إلى GitHub ثم اربطه بـ Vercel. لا يوجد Build Command مطلوب.
